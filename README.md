# Ramp Desktop

<img src="https://raw.githubusercontent.com/FreedomForeverSolar/ramp/main/docs/images/app-icon.png" width="128" align="right">

**macOS desktop application for [Ramp](https://github.com/FreedomForeverSolar/ramp) - the multi-repository development workflow tool.**

## Download

Download the latest release from the [Releases](https://github.com/FreedomForeverSolar/ramp-desktop/releases) page.

### Requirements

- macOS 11.0 (Big Sur) or later
- Apple Silicon (M1/M2/M3) or Intel

## About

Ramp Desktop provides a visual interface for managing multi-repo projects:

- Browse and manage projects
- Create and delete features across repositories
- Run custom commands
- Real-time progress updates
- One-click feature creation

For documentation on using Ramp, see the [main repository](https://github.com/FreedomForeverSolar/ramp).

## CLI Installation

The desktop app works alongside the Ramp CLI. Install the CLI via Homebrew:

```bash
brew install freedomforeversolar/tools/ramp
```
